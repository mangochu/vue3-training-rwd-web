# 01. 設計參考與線框圖

## 目標

- 找到 1～2 個想參考的網站
- 畫出**手機、平板、桌機**三種寬度的線框圖（Wireframe）
- 定好 **Design Tokens**（顏色、字級、間距、斷點），寫程式時直接照用

## 2. 線框圖（Wireframe）

下面是一份建議的線框圖，可以直接照做，也可以改成你自己的版本。

### 手機版（< 768px）：單欄

```
┌─────────────────────┐
│ [Logo]          [≡] │ ← Header 固定在頂部，導覽收進漢堡選單
├─────────────────────┤
│                     │
│     Hi, I'm XXX     │ ← Hero：字級較小、置中
│  Frontend Developer │
│  [看作品] [履歷]     │ ← 按鈕可以垂直排或並排
│                     │
├─────────────────────┤
│      ( 頭像 )        │ ← About：圖在上
│  自我介紹文字……       │    文字在下
│  [Vue][TS][CSS]...  │ ← 技能標籤自動換行（flex-wrap）
├─────────────────────┤
│ [All][Vue][React]   │ ← 篩選按鈕可以橫向捲動
│ ┌─────────────────┐ │
│ │   作品卡片 1     │ │ ← 卡片一欄
│ └─────────────────┘ │
│ ┌─────────────────┐ │
│ │   作品卡片 2     │ │
│ └─────────────────┘ │
├─────────────────────┤
│ ● 2024 公司 A        │ ← Resume：時間軸線在左邊
│ │  職稱 / 說明        │
│ ● 2022 學校 B        │
├─────────────────────┤
│  Contact / Footer   │
└─────────────────────┘
```

### 平板版（768px ～ 1023px）：兩欄卡片

```
┌───────────────────────────────────┐
│ [Logo]    About Projects Resume … │ ← 導覽列攤開
├───────────────────────────────────┤
│            Hi, I'm XXX            │
├───────────────────────────────────┤
│ ( 頭像 ) │ 自我介紹文字……           │ ← About：圖文左右並排
├───────────────────────────────────┤
│ ┌─────────────┐ ┌─────────────┐   │
│ │   卡片 1     │ │   卡片 2     │   │ ← 卡片兩欄
│ └─────────────┘ └─────────────┘   │
└───────────────────────────────────┘
```

### 桌機版（≥ 1024px）：限制最大寬度、三欄卡片

```
┌─────────────────────────────────────────────────┐
│ [Logo]                About Projects Resume Contact │
├─────────────────────────────────────────────────┤
│     ┌──────── max-width: 1120px ────────┐       │
│     │ Hi, I'm XXX              (插圖)   │       │ ← Hero 左文右圖
│     ├───────────────────────────────────┤       │
│     │ [卡片1]   [卡片2]   [卡片3]        │       │ ← 卡片三欄
│     │ [卡片4]   [卡片5]   [卡片6]        │       │
│     ├───────────────────────────────────┤       │
│     │ 2024 ──●── 公司 A：職稱 / 說明      │       │ ← 時間軸可改成左右交錯
│     └───────────────────────────────────┘       │
└─────────────────────────────────────────────────┘
```

### 自己畫線框圖（擇一）

- **紙筆**：最快，拍照存進 `docs/design/` 就可以
- **Figma**（免費方案即可）：
  1. 新增 Design file，用 Frame 工具（`F`）右側的預設尺寸建立 `iPhone 13 mini (375)`、`iPad mini (768)`、`Desktop (1440)` 三個畫框
  2. 只用灰色方塊 + 文字，**不要現在就調顏色**
  3. 練習 Auto Layout（`Shift + A`）：它的觀念和 CSS Flexbox 幾乎一樣，對你等一下寫 CSS 很有幫助
- **Excalidraw**（[excalidraw.com](https://excalidraw.com)）：免安裝的手繪風白板

## 3. Design Tokens

Design Tokens 是一份「設計規格表」。先定好，寫 CSS 時只用這些值，畫面就會一致。
第 04 章會把它們寫成 CSS 變數。

### 顏色（範例，可自行替換）

| Token | 淺色模式 | 深色模式（第 09 章用） | 用途 |
| --- | --- | --- | --- |
| `--color-bg` | `#ffffff` | `#0f172a` | 頁面背景 |
| `--color-surface` | `#f8fafc` | `#1e293b` | 卡片背景 |
| `--color-text` | `#0f172a` | `#e2e8f0` | 主要文字 |
| `--color-text-muted` | `#64748b` | `#94a3b8` | 次要文字 |
| `--color-primary` | `#4f46e5` | `#818cf8` | 主色（按鈕、連結） |
| `--color-border` | `#e2e8f0` | `#334155` | 邊框 |

> 主色挑選工具：[coolors.co](https://coolors.co)、[Tailwind 色票](https://tailwindcss.com/docs/colors)（只看色票，不裝 Tailwind）。
> 檢查文字對比度：[WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)，一般文字要達到 **4.5:1**。

### 字級

| Token | 值 | 用途 |
| --- | --- | --- |
| `--font-sans` | `"Noto Sans TC", system-ui, sans-serif` | 內文 |
| `--fs-sm` | `0.875rem` | 標籤、註解 |
| `--fs-base` | `1rem` | 內文 |
| `--fs-lg` | `1.25rem` | 小標 |
| `--fs-xl` | `clamp(1.5rem, 1.2rem + 1.5vw, 2rem)` | 區塊標題 |
| `--fs-hero` | `clamp(2rem, 1.2rem + 4vw, 4rem)` | Hero 大標 |

> `clamp(最小值, 理想值, 最大值)` 能讓字級隨螢幕寬度平滑縮放，不用寫一堆 media query。第 04 章會解釋。

### 間距（以 4px / 8px 為基準）

| Token | 值 |
| --- | --- |
| `--space-1` | `0.25rem`（4px） |
| `--space-2` | `0.5rem`（8px） |
| `--space-3` | `1rem`（16px） |
| `--space-4` | `1.5rem`（24px） |
| `--space-5` | `2rem`（32px） |
| `--space-6` | `4rem`（64px） |

### 斷點（Breakpoints）

| 名稱 | 最小寬度 | 代表裝置 |
| --- | --- | --- |
| （預設） | 0 | 手機 |
| `md` | `768px` | 平板 |
| `lg` | `1024px` | 小筆電 |
| `xl` | `1280px` | 桌機 |

> 斷點不需要很多，**3 個就夠了**。原則是：內容開始變醜的寬度，就是你的斷點。

<details>
<summary>卡關提示：為什麼用 rem？</summary>

使用者在瀏覽器設定把預設字級調大時（視力不好的人常這樣做），`rem` 會跟著放大，`px` 不會。
`1rem` 預設等於根元素（`<html>`）的字級，通常是 16px。

</details>
